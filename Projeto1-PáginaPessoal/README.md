## Sobre o projeto

Este projeto foi desenvolvido como prática de HTML5 e CSS3, com o objetivo de criar uma página pessoal que apresente minha trajetória, meus interesses e meus objetivos de aprendizagem.

## Páginas do site

- **Página inicial (`index.html`):** apresentação pessoal, trajetória, interesses, objetivos de aprendizagem, tabela de estudos e contato demonstrativo.
- **Meus interesses (`página/interesses.html`):** página complementar sobre minhas experiências com RPG de mesa e minha relação com a música, incluindo imagens e um player de áudio.

## Como abrir o projeto

1. Baixe ou copie a pasta completa do projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Utilize os links de navegação para acessar as seções e a página complementar.

Os arquivos locais devem permanecer nas pastas originais para que imagens, estilos e áudio sejam carregados corretamente.

## Tecnologias e recursos utilizados

- HTML5 para estruturar o conteúdo.
- CSS3 para cores, espaçamento, organização visual e adaptação a telas menores.
- Imagens locais armazenadas na pasta `imagens/`.
- Arquivo de áudio local armazenado na pasta `midias/`.
- Links internos, links externos, listas, tabela e formulário demonstrativo.
